Your API key stays in this browser only (localStorage) — it is never written into these files and never uploaded anywhere except to Anthropic when a review runs. Scans are sent to the Claude API to be read; nothing else leaves this machine.

Get a key at console.anthropic.com → API keys. It is saved in this browser and stays until you clear site data or press Forget — you only type it once.
