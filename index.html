1 · Setup

Your API key stays in this browser only (localStorage) — never written into these files, never sent anywhere but the AI provider you pick below. Page images of your scans go to that provider to be read; nothing else leaves this machine.

The provider is recognised from the key, and the most capable model it can reach is chosen automatically. Keys: console.anthropic.com, platform.openai.com or aistudio.google.com.

Override the model  

No API key? Use Google AI Studio free

aistudio.google.com is free in the browser — no key, no card — and runs a better model than any free API tier. It is a chat window rather than an API, so this does everything around it: it turns your folder into numbered page images, writes the prompt, and takes the reply back to produce the same query sheet. Your pages never pass through this app's server, because it hasn't got one.

  1. then open aistudio.google.com and paste it in
  2. — unzip and upload the images to that chat
  3. Let it answer, then copy its whole reply and paste it below

1b · Teach it your wording

Import a finished Query Sheet and every observation in it becomes a worked example. The model is shown these before it writes, so the more corrected sheets you feed in, the closer the output gets to your own phrasing. They stay in this browser and are never uploaded.
